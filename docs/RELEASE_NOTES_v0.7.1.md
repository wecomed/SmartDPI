# SmartDPI 0.7.1

修复显示器长时间关闭后，完整模式较晚恢复时可能不再自动开启 HiDPI 的问题，并明确提示系统识别降级。

- 初次恢复超时后保留恢复请求。显示器编号不变也能在完整模式重新可用后继续恢复；每轮仍有限等待、最多 3 次切换，不因同一份模式列表反复配置。
- 屏幕仍被系统标为唤醒，但自有虚拟镜像与已知面板能力同时丢失时，按重连处理；完整模式下的外部手动更改不会触发强制恢复。
- 原配置恢复尚未完成时保留待恢复的 HiDPI，模式恢复后先清理原配置，再继续所选尺寸。用户取消后不会因后台观察而重新排队。
- 状态栏和主窗口区分“系统报告”与“已记录面板”。识别暂时退到 900p 时，显示“识别不完整”，不会把它写成显示器物理分辨率。提示区域高度固定，避免列表跳动。
- 导出的诊断增加待恢复、等待能力变化和基线恢复状态。

## 使用与验证边界

保持 SmartDPI 运行，开启“重新连接后恢复 HiDPI”，选择一次所需尺寸即可。系统迟迟不提供完整模式时，可在“系统设置 → 显示器”按住 Option 点击“检测显示器”，或重新连接显示器。[Apple 排查说明](https://support.apple.com/en-gb/102501)

本次异常现场读取到同一红米 P27QBA-RA 的模式列表暂时缺少 2560 × 1440，当前变为 1600 × 900 / 60 Hz；用户再次开关后恢复 1920 × 1080 HiDPI / 75 Hz。软件修复的是恢复逻辑和错误提示，未确认识别降级的硬件或系统根因，也不能生成系统未提供的物理输出模式。

114 项自动化测试通过，覆盖 900p 降级、超时后同编号模式晚到、刷新率、取消、多显示器隔离及避免无限重试。隔夜可靠性仍需后续实际使用验证，不以短时测试代替。

安装包为 Apple Silicon arm64，最低 macOS 13。仍使用临时签名，尚未经过 Developer ID 签名与 Apple 公证；首次打开请按安装指南操作。
