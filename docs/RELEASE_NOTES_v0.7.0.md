# SmartDPI 0.7.0

本版增加显示器重连后的 HiDPI 自动恢复，并修复关屏、拔线时丢失原显示配置的问题。

## 新功能与修复

- 主窗口和菜单栏新增“重新连接后恢复 HiDPI”，默认开启。成功选择一次 HiDPI 后，保存该显示器的桌面尺寸和刷新率偏好；App 运行时在屏幕唤醒、重连和下次启动时恢复。
- 使用显示器稳定标识匹配，兼容重新连接后数字编号改变；同型号屏幕不互相套用设置。标识以哈希形式保存在本机，不保存原始硬件序列号。
- 等待完整模式列表稳定后应用；临时 720p 不会覆盖已保存的 HiDPI。自动刷新率按连接匹配，明确选择的 Hz 不可用时暂停而不静默降频。
- 断开或睡眠期间保留恢复快照，重新连接后从当前模式列表重新匹配原模式。自动恢复不会解除其他应用建立的镜像。
- 自动尝试次数与等待时间有限；可用“重试”按钮重新检测。手动选择普通模式会清除该显示器保存的 HiDPI；手动恢复原设置会取消本轮自动操作。
- 诊断导出增加自动恢复设置与恢复状态；诊断命令和界面预览不会启动自动切换。

## 使用

打开 SmartDPI，保持“重新连接后恢复 HiDPI”开启，成功选择一次需要的 HiDPI 尺寸。下方出现“下次恢复 …”后即可关屏重开测试；需要保持 SmartDPI 在后台运行。本版没有自动注册开机登录项，退出 App 后无法处理屏幕事件。当前同时只能维护一台虚拟 HiDPI 显示器。

推荐下载 DMG，退出旧版后将新 App 拖到“应用程序”。应用仍使用临时签名，尚未经过 Developer ID 签名与 Apple 公证；首次打开的说明随 DMG 提供。

## 720p 与 USB-C 识别

如果退出 SmartDPI 后也出现低分辨率，仍需排查 USB-C 重新握手、线材和系统模式识别。软件只能使用 macOS 实际提供的模式，不能保证修复所有硬件关屏问题。可在“系统设置 → 显示器”按住 Option 点击“检测显示器”，必要时重新连接或对比 HDMI。[Apple 排查步骤](https://support.apple.com/102501)

101 项自动化测试通过，验证覆盖稳定身份、重新连接编号改变、离线与睡眠、临时 720p、不支持的刷新率、取消操作、有限重试及偏好持久化。真实红米显示器的关电/开电、USB-C/HDMI 切换仍需实机验证，不以自动化测试替代硬件结论。
