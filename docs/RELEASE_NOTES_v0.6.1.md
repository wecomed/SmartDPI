# SmartDPI 0.6.1

本版改进下载后的安装引导，帮助用户分清 macOS 首次打开提示与真正的文件损坏问题。SmartDPI 继续面向所有在 macOS 上未适配 HiDPI、缺少 HiDPI 模式或合适缩放选项的显示器，用途不限于 2K。

## 安装体验

- 新增 DMG 安装镜像，将 `SmartDPI.app` 拖入同一窗口的“应用程序”即可安装；保留 ZIP 下载方式。
- DMG 内附有可离线阅读的“安装说明.html”，覆盖安装、首次打开与菜单栏选择 HiDPI 的步骤。App 被系统拦截时，也能先阅读说明。
- README 与安装说明明确解释“移到废纸篓”是部分安全提示的按钮，应依据提示正文判断原因。
- 区分未验证开发者 / 未公证提示、文件“已损坏”提示与“将损坏你的电脑”提示，分别说明官方允许打开入口、重新下载校验与停止使用反馈。

## 下载与首次打开

推荐下载 `SmartDPI-0.6.1-macOS-arm64.dmg`，打开后将 App 拖入“应用程序”，再从“应用程序”启动。ZIP 用户先解压，再将 App 拖入“应用程序”。安装完成可推出 DMG。

**本版本仍采用临时（ad-hoc）签名，没有 Apple Developer ID 签名，未经过 Apple 公证。** DMG 改善安装引导，不会消除 Gatekeeper 检查。若提示无法验证开发者或 Apple 无法检查恶意软件，仅在确认来自官方发布页、文件未被更改并信任该来源后，按 [Apple 的官方步骤](https://support.apple.com/102445)，在尝试打开后查看“系统设置 → 隐私与安全性”是否出现 SmartDPI 的“仍要打开”入口。

若提示“已损坏”，重新下载并核对同版本 `SHA256SUMS.txt`；仍有问题应反馈开发者，不直接视为未公证提示。若提示“将损坏你的电脑”或检测到恶意软件，请停止运行并反馈，不要尝试绕过。校验值一致不能代替恶意软件检查或 Apple 公证。安装流程不要求关闭 Gatekeeper、SIP，或删除隔离标记。

## 兼容性与使用范围

- Apple Silicon arm64，最低运行目标 macOS 13；面向 M1 及后续 M 系列，未逐台实机验证所有芯片。
- 本次安装包装更新沿用 0.6.0 的显示模式、即时应用与恢复机制，不扩展硬件兼容性承诺。
- 系统已有模式优先使用；缺少 HiDPI 时尝试实验性的虚拟显示与系统镜像，需保持 App 运行。可用分辨率和刷新率取决于 Mac、系统、显示器、接口及线材。
- 本版 69 项自动化测试通过。此前实际读取到的硬件场景为 Apple M6 / macOS 27.0.1 上的 HiDPI 虚拟镜像；高负载、色彩、睡眠唤醒及其他芯片尚未完整实机验证。

签名与公证的区别可查阅 [Apple Developer ID 说明](https://developer.apple.com/developer-id/)。完整安装指引见仓库 `docs/INSTALLATION.html` 或 DMG 内“安装说明.html”。
