# SmartDPI 0.6.0

SmartDPI 是一个原生 macOS 菜单栏工具，面向在 macOS 上没有适配 HiDPI、缺少 HiDPI 模式或合适缩放选项的显示器，帮助选择舒适的桌面大小并尝试补充缺失的 HiDPI。用途不限于某种分辨率。

## 解决什么问题

显示器连接 Mac 后，可能因为系统适配、显示模式或连接方式的限制，无法选择 HiDPI，或只有少数不合适的缩放尺寸。这种情况可能发生在不同分辨率、比例和尺寸的显示器上。直接降低普通分辨率可能让文字变糊，保留原生桌面又可能让文字和按钮太小。

SmartDPI 将分辨率、HiDPI 开关和可用刷新率放在同一个列表中。以一种常见使用场景为例：在 **2560 × 1440 的 2K 面板**上，选择 **“1920 × 1080 · HiDPI 开”**，获得接近 1080p 的界面大小。面板物理像素仍是 2560 × 1440；内部可能先以 3840 × 2160 绘制，再缩放到面板，不能增加真实物理像素。

## 本版功能

- 菜单栏直接选择分辨率，主窗口与快捷面板使用同一份列表。
- 所有模式合并显示，只区分“HiDPI 开 / 关”，并标明实际当前状态。
- 点击立即应用，不需要第二次确认保留设置；提供“恢复原设置”入口。
- 刷新率支持自动匹配，也可手动选择该模式实际提供的频率，保留小数 Hz。
- 优先使用 macOS 已有模式，缺少 HiDPI 时尝试虚拟显示与系统镜像。
- 固定列表行高、反馈区域与快捷面板高度，减少模式切换造成的界面位移。
- 新显示器与缩放箭头图标；使用 macOS 27 SDK、原生侧栏和系统控件，跟随深浅色及降低透明度设置。
- 缓存显示模式列表，显示变化事件触发更新，降低周期性完整扫描次数；虚拟镜像运行时保留轻量健康检查。
- 只读诊断导出与性能采样脚本，便于定位不同设备的显示差异。

## 安装

下载 `SmartDPI-0.6.0-macOS-arm64.zip`，解压后将 `SmartDPI.app` 拖入“应用程序”。详细步骤见同一 Release 的 `INSTALL.txt`，下载完整性可使用 `SHA256SUMS.txt` 校验。

此版本仅使用临时（ad-hoc）签名，未经过 Apple Developer ID 签名或公证。若 macOS 阻止打开，请核对来源与校验值，尝试打开一次后前往“系统设置 → 隐私与安全性”，在对应提示旁选择“仍要打开”。

## 兼容性与使用边界

- **架构：** Apple Silicon arm64，面向 M1 及后续 M 系列，包括对应 Pro / Max / Ultra；最低运行目标 macOS 13。可运行不代表所有机器提供相同模式。
- **实机范围：** 已在 Apple M6 / macOS 27.0.1 上读取到 2K 面板的 1920 × 1080 HiDPI 虚拟镜像及系统报告的 75 Hz。其他 M 系列、旧系统、高负载、色彩与睡眠唤醒尚未逐项实机验证。
- **虚拟镜像：** 使用未公开的 `CGVirtualDisplay` 接口，运行时检测能力并核对实际模式。系统设置出现虚拟显示器和镜像关系属于该方案的正常表现；此时需保持 App 运行，退出、睡眠或断开时释放虚拟显示。启动不会自动重新启用上次的虚拟模式。
- **恢复：** 切换失败时请求恢复，也可随时点击“恢复原设置”。已成功应用的普通系统模式不会仅因退出 App 自动撤销。
- **性能：** App CPU、内存并不包含所有 GPU 与 WindowServer 开销；HiDPI 的较大渲染画布、高刷新率和动态内容会增加图形工作量。
- **验证：** 69 项自动化测试通过；发布 App 的 arm64 架构、最低系统版本及签名完整性已校验。系统玻璃材质的实际合成外观不能仅靠离屏截图保证。

SmartDPI 不修改显示器 EDID、系统 Overrides、SIP 或管理员设置，系统镜像路径无需屏幕录制权限。可用分辨率与刷新率由当前 Mac、macOS、显示器、接口和线材共同决定。
