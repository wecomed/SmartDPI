SmartDPI 安装与首次打开 · 0.6.1

装好以后，
从菜单栏选择舒适的大小。

为在 macOS 上未适配 HiDPI 的显示器提供缩放选择。
先把 App 放进“应用程序”，再完成首次打开。

Apple Silicon · M1 及后续 M 系列 · macOS 13+
  1. 1

    拖入“应用程序”

    打开 DMG，将 SmartDPI.app 拖到同一窗口的“应用程序”文件夹。ZIP 用户先解压，再拖入 Finder 的“应用程序”。

  2. 2

    从“应用程序”打开

    双击安装好的 SmartDPI。首次打开如遇系统提示，先对照下面的说明。完成安装后可以推出 DMG。

  3. 3

    在菜单栏选 HiDPI

    点击顶部菜单栏的显示器图标，选择目标屏幕和“HiDPI 开”的桌面大小。点击立即生效；需要返回时选“恢复原设置”。

看到“移到废纸篓”，先看提示正文。

这是 macOS 的安全检查界面。“移到废纸篓”可能只是提示中的一个按钮，单看这个按钮还不能确定 App 已损坏。

当前发布状态：SmartDPI 使用临时（ad-hoc）签名，没有 Apple Developer ID 签名，也未经过 Apple 公证。DMG 让安装步骤更清楚，不能消除系统的安全检查。App 内的引导也要在系统允许启动后才能显示。

当前版本首次打开可能遇到 · 开发者身份 / 公证提示

“Apple 无法检查是否包含恶意软件”
或“无法验证开发者”

这类提示与当前尚未公证的发布状态相符。如果你决定继续，请先确认来源和文件：

  1. 确认从 wecomed/SmartDPI 官方 Releases 下载；需要时按下方方法核对同版本 SHA256。
  2. 尝试打开一次后，进入“系统设置 → 隐私与安全性”，向下查看安全性区域。
  3. 只有确认信任此来源，且出现 SmartDPI 的对应条目时，才选择“仍要打开”（部分系统文案可能为“仍然允许”），再按系统提示确认。

没有对应条目时不要寻找强制绕过命令。单位管理的 Mac 可能需要管理员处理；也可向项目反馈完整提示。

文件损坏 / 完整性问题

“已损坏，无法打开”

先取消打开，重新从官方发布页下载同版本文件，并核对 SHA256。仍然提示损坏时，向项目提交完整提示、macOS 版本、下载链接与校验结果，由开发者检查打包和签名问题。

不要把“已损坏”直接当成普通的未公证提示，也不要删除隔离标记来强行运行。

停止使用并反馈

“将损坏你的电脑”或检测到恶意软件

停止打开该文件，按系统提示处理，不要尝试强行运行。记录完整提示、下载链接与校验值，在 项目 Issues 中反馈，等待核查或修复。

可选：核对下载完整性

从同一 Release 下载 SHA256SUMS.txt。在“终端”输入 shasum -a 256 和一个空格，把下载的 DMG 或 ZIP 拖到终端，再按回车。将输出与校验文件中对应文件那一行比较。

校验值一致，说明下载文件与发布资产相同；它不能代替恶意软件检查或 Apple 公证。不一致时不要运行，请重新下载。

开始使用前了解两点

“看起来像”的尺寸决定文字和窗口大小；物理面板的像素不会改变。SmartDPI 面向各种缺少 HiDPI 适配的显示器，可用尺寸和刷新率取决于实际设备与连接。

缺少系统 HiDPI 模式时，SmartDPI 会尝试虚拟屏幕与系统镜像；系统设置中出现镜像属于正常表现，此时需保持 App 运行。可运行架构不代表所有 M 系列都已逐机测试。

本页随安装包提供，可离线阅读；只有点击链接时才会访问对应网站。安装不要求关闭 Gatekeeper、SIP，或删除下载隔离标记。
